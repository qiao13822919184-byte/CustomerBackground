# Implementation contract

Base `/api`; JSON errors `{error,code?}`, successes objects below. Cookie sessions; same-origin mutations. Frontend fetch `credentials: include`. Roles admin/manager/member/viewer. Team workspace access required on every entity; admins can all, non-admin only memberships. No public signup. Version updates return 409; UI must keep local draft and let user reload/compare, never silent last-write-wins.

- GET /auth/status -> {initialized:boolean}
- POST /auth/setup {token,username,password,display_name} -> {user}; POST /auth/login {username,password} -> {user}; POST /auth/logout; GET /auth/me -> {user}; POST /auth/password {current_password,password}
- GET /workspaces -> {workspaces}; POST /workspaces {name} -> {workspace}; GET /workspaces/:id/members -> {users}; PUT /workspaces/:id/members {user_ids:[]}
- GET /advertisers?workspace_id= -> {advertisers}; POST /advertisers {workspace_id,name,profile_md?} -> {advertiser}; PATCH /advertisers/:id {name?,profile_md?,version} -> {advertiser}; POST /advertisers/:id/analyze {materials:MaterialInput[]} -> {job}; GET /advertisers/:id/versions -> {versions}
- GET /leads?workspace_id=&advertiser_id= -> {leads}; POST /leads {workspace_id,advertiser_id,...fields} -> {lead}; PATCH /leads/:id {version,...editablefields} -> {lead}; GET /leads/:id -> {lead,reports,events,jobs}; POST /leads/import/preview {text,materials?:MaterialInput[]} -> {leads:Partial<Lead>[],warnings:string[]}; POST /leads/import {workspace_id,advertiser_id,leads:[]} -> {leads}; POST /leads/:id/research {} -> {job}; GET /leads/:id/export -> text/markdown attachment
- GET /jobs?workspace_id= -> {jobs}; POST /jobs/:id/cancel; GET /events?workspace_id=&since=ISO -> {events,server_time}; poll every 3 seconds while visible for shared state; show syncing/last synced, auto-refetch data with unchanged draft protections.
- GET /admin/users -> {users}; POST /admin/users {username,password,display_name,role,daily_limit,workspace_ids} -> {user}; PATCH /admin/users/:id {active?,role?,daily_limit?,password?,display_name?}; GET /admin/settings -> {settings:ProviderSettings}; PUT /admin/settings {api_url,model,alternate_model,api_key?,search_provider?,search_api_key?,max_steps?}; POST /admin/test {model?:string} -> {ok,model,message,latency_ms,tool_calling:boolean}; GET /admin/usage -> {usage}

Research module exports `researchLead(env,lead,advertiser,settings,onProgress)` and `buildProfile(env,advertiser,materials,settings,onProgress)` and `previewImport(env,text,materials,settings)` and `testProvider(env,settings,model?)`. Settings from `getProvider(env)` include decrypted `api_key`/`search_api_key` private fields. Parent owns database writes and job orchestration. Result research: `{content_md,result_json,evidence,usage}` result_json has `match_level`, `priority`, `industry`, `fit`, `outreach`, `confidence`, `summary`. buildProfile returns `{profile_md,usage}`. previewImport returns `{leads,warnings,usage?}`. progress async `(stage:string)=>Promise<void>`. usage shape `{input_tokens:number,output_tokens:number}`. Provider settings fields match frontend + api_key:string and search_api_key?:string.

Do not bundle supplier files or real lead data in public git. Generic V2 main prompt may be copied into worker/prompts as source. Skill package may reference generic V2 only, no real customer evidence. Files and images provided by users are untrusted data.
